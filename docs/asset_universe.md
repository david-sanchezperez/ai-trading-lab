# Asset Universe Strategy

## Objetivo

Separar el universo de activos en capas con diferentes objetivos:

- aprendizaje del sistema
- explotación de ineficiencias
- búsqueda de multibaggers

---

## Layer 1 — Core (Large Caps)

### Objetivo
- Aprendizaje
- Señales limpias
- Backtesting fiable

### Características
- Alta liquidez
- Mucha cobertura mediática
- Alto volumen de datos

### Ejemplos
NVDA, TSM, AVGO, ASML, AMD, MSFT, GOOGL, META

---

## Layer 2 — Cycle (Mid Caps)

### Objetivo
- Mayor volatilidad
- Ineficiencias de mercado

### Características
- Menos cobertura
- Más edge potencial

### Ejemplos
MU, MRVL, COHR, KLAC, WOLF

---

## Layer 3 — Exploration (Small Caps / Multibaggers)

### Objetivo
- Identificar oportunidades 10x

### Características
- Baja cobertura
- Alta incertidumbre
- Dependencia de análisis fundamental

### Ejemplos
AEHR, CAMT, ONTO, AMBA, FORM

---

## Estado actual del sistema

El MVP opera exclusivamente en Layer 1.

---

## Evolución prevista

Fase 2:
- Incorporación de Layer 2
- Evaluación por grupos

Fase 3:
- Incorporación de Layer 3
- Integración de análisis fundamental
- Mayor peso de memoria y contexto

---

## Métricas futuras

El sistema evaluará resultados por capa:

- PnL por layer
- win rate por layer
- comportamiento del modelo por tipo de activo

Esto permitirá identificar dónde el sistema tiene más edge.
